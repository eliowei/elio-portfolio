# ============================================================================
# Engineering Challenges
# 技術挑戰
# ============================================================================

challenges:

- title: SEO 架構規劃
  subtitle: Search Optimization
  problem: >
    個人網站需要具備良好的搜尋能見度，
    同時兼顧內容維護與頁面效能。

  solution: >
    透過 Nuxt SSR、Meta 管理與 Sitemap 建立，
    提升搜尋引擎索引效率與網站曝光度。

  technologies:
    - Nuxt SEO
    - Sitemap

- title: 頁面轉場體驗
  subtitle: User Experience

  problem: >
    頁面切換過於生硬，
    容易降低整體瀏覽體驗。

  solution: >
    使用 GSAP 建立 Page Transition 與動畫效果，
    提升網站的互動感與品牌印象。

  technologies:
    - GSAP
    - Vue Transition

- title: 內容架構設計
  subtitle: Content Architecture

  problem: >
    隨著作品數量增加，
    若缺乏統一資料結構，
    容易造成維護成本提高與版面不一致。

  solution: >
    使用 Nuxt Content 與 Markdown 建立內容驅動架構，
    將作品資料結構化管理，
    讓頁面能透過相同模板快速產生內容。

  technologies:
    - Nuxt Content
    - Markdown
